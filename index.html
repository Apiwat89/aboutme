เกี่ยวกับผม

ผมเป็นนักศึกษาจบใหม่สาขา เทคโนโลยีสารสนเทศ จากมหาวิทยาลัยเทคโนโลยีพระจอมเกล้าพระนครเหนือ สนใจทั้งฝั่ง Web Development และ Data Science / Machine Learning จึงเลือกฝึกฝนทั้งสองด้านคู่กันตลอดช่วงที่เรียน

ระหว่างเรียนได้ลงมือทำโปรเจกต์จริงหลายชิ้น ตั้งแต่เว็บแอปพลิเคชันแบบ full-stack ไปจนถึงโมเดล deep learning สำหรับงานตรวจจับภาพ และเคยผ่านการฝึกงานที่ได้ใช้ทั้งทักษะการเขียนโปรแกรมและการทำงานร่วมกับข้อมูลจริง

"ยังไม่มีผลงานเยอะ แต่ทุกโปรเจกต์คือของจริงที่ลงมือทำเองตั้งแต่ต้นจนจบ"

นอกจากนี้ ผมปรับตัวและนำ AI-Assisted Development เข้ามาเป็นส่วนหนึ่งของกระบวนการทำงานอย่างจริงจัง มอง AI เป็นเหมือน Pair Programmer ที่ช่วยระดมไอเดีย สรุปโครงสร้าง หาแนวทางแก้ปัญหาเฉพาะทาง และตรวจสอบโค้ด (Code Review) แต่ยังคงยึดหลักการทำความเข้าใจ Logic, Data Flow และ Fundamental ด้วยตัวเองเสมอ เพื่อให้มั่นใจว่าทุกโค้ดที่นำมาใช้ ปลอดภัย มีประสิทธิภาพ และเราสามารถควบคุม ดูแลรักษาต่อได้จริง

นอกเวลาเรียน ชอบศึกษาเครื่องมือ เฟรมเวิร์ก และเทคนิคใหม่ ๆ อยู่เสมอ พร้อมเรียนรู้และปรับตัวอย่างรวดเร็วเพื่อสร้างสรรค์ผลงานที่มีคุณค่าต่อทีม
